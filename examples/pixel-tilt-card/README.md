# Examples

`field-notes.html` is a four-card deck built by this skill — the repo
owner's own photos, published deliberately as an illustration of the
effect. Open it in any browser (or view the [live
demo](https://lingjiefeng.github.io/aesthetic-ops/examples/pixel-tilt-card/field-notes.html)):
hover to tilt, arrows or ←/→ to flip between cards.

`demo.gif` is the screen recording used in the top-level README (GitHub
strips `<video>` tags, so the inline demo has to be a GIF); `demo.mp4` is
the same recording at full quality.

Nothing here is required by the skill — the working parts live in
[`plugins/pixel-tilt-card/`](../../plugins/pixel-tilt-card/). These files sit
outside the plugin on purpose, so installing it doesn't pull down 5MB of
demo material.
